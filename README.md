## 📊 Projects Highlights

Below are some of my notable projects. Click on the links to learn more:

1. **[NoteDo App](https://github.com/Muhamed-Hashesh/NoteDo-App.git)**
   - **Description**: NoteDo is an all-in-one productivity app that combines note-taking, to-do lists, translation, and a calculator. It also features a sleek dark mode for better usability in low-light environments.
   - **Key Features**:
     - Create and manage notes with rich text formatting.
     - Organize tasks with a to-do list feature.
     - Built-in translator for quick translations between multiple languages.
     - A simple calculator for quick calculations.
     - Dark mode for enhanced user experience.
   - **Technologies Used**: Flutter, Provider State Management, Hive Database

2. **[Quran App](https://github.com/Muhamed-Hashesh/QuranApp-repo.git)**
   - **Description**: QuranApp is a comprehensive Islamic app designed to help users deepen their connection with Islam. It includes Quran recitations, religious books, sermons, prayer times, and daily reminders.
   - **Key Features**:
     - Full Quran with audio recitations from multiple reciters.
     - Access to religious books, lectures, and sermons.
     - Prayer time notifications based on the user's location.
     - Daily reminders for supplications (Adhkar).
     - Beautiful UI with a focus on simplicity and accessibility.
   - **Technologies Used**: Flutter, Firebase, REST APIs for prayer times, Audio Players

3. **FreeGency**
   - **Status**: On Progress
   - **Description**: FreeGency is a project currently under development. It aims to provide a platform for freelancers and agencies to connect, collaborate, and manage projects efficiently. More details will be available soon!
